実測してから採用する

完全な行動集合の一致を確認し、同じ局面群で交互に6回ずつ計測します。

これから比較する項目

探索候補数・深い探索の割合・過去モデル対戦・リプレイの再利用率を、一度にひとつずつ変更して同じ計算時間で比較します。Magic Bitboard、NNUE、深いSM-MCTS、優先度付きリプレイ、量子化は、現在の計測結果で効果を確認してから導入します。

1段の候補探索と近似局面評価による初期基盤です。ゲーム全体のNash均衡、万能な最適戦略、棋力の向上は未検証です。ルールの代替案は将来、別の版・ハッシュとして記録します。
