# Shogi Brush

`shogi-brush.ttf` contains the 15 piece glyphs from [Yuji Boku](https://github.com/google/fonts/tree/main/ofl/yujiboku), designed from calligraphy by Yuji Kataoka. Copyright 2021 The Yuji Project Authors. Distributed under the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).

The Google Fonts text-subsetting API produced this 11.6 KB TrueType asset. Regenerate it with `node scripts/prepare-piece-font.mjs`. Builds and gameplay use only this local file and make no requests to a font service.
